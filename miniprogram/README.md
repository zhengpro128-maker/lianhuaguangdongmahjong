# 微信小程序 H5 验证壳

这是一个最小可运行的微信小程序项目：它只用 `web-view` 承载现有的 Vue H5 游戏，**不改动游戏业务代码、Three.js 渲染或房间协议**。它用于验证微信真实客户端中的 WebGL、横屏、音频和联机表现；不是原生小程序重写版。

## 临时真机验收：只有公网 IP 也可以

这条路径只用于**你自己的开发者微信**扫码预览，不需要发布或备案：

1. 确认手机能直接访问游戏，例如在手机浏览器先打开 `http://<阿里云公网IP>:<端口>/`。若打不开，先在阿里云安全组、服务器防火墙和反向代理中放行该端口。
2. 编辑 [config.js](./config.js)，把 `GAME_WEB_URL` 改为这个地址；地址末尾保留 `/`。
3. 在微信开发者工具导入 `miniprogram/`，并把 `project.config.json` 的 `appid` 改为你的测试号或小程序 AppID。
4. 在“详情 → 本地设置”勾选“**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**”，点击编译，先在模拟器确认页面能够打开。
5. 点击工具栏“预览”生成二维码，用该 AppID 的开发者微信扫码。在手机小程序右上角“…”中打开“调试”（不同微信版本名称可能略有不同），重新进入该预览小程序。
6. 按“真机验收清单”验证横屏、音频、3D、创建/加入房间与断线重连。

这个绕过仅对开启调试的开发者账号有效；普通用户、体验版和正式发布仍必须使用配置好的 HTTPS 业务域名。

## 正式域名验收前准备

1. 在与当前分支相同的提交上构建并部署 H5：`pnpm build`。
2. 用 HTTPS 域名托管 `dist/`，并让同一个域名通过反向代理提供 `/api` 与 `/ws`。现有前端默认使用页面同源的 API，因此这一步不需要修改 H5 配置。
3. 将 H5 地址填入 [config.js](./config.js) 的 `GAME_WEB_URL`。地址必须以 `/` 结尾，例如 `https://mahjong.example.com/`。
4. 在微信公众平台的“小程序后台 → 开发管理 → 开发设置”中添加该域名为**业务域名**，并按平台要求放置域名校验文件。使用真机预览、体验版和正式版都不能跳过这一步。
5. 在微信开发者工具导入本 `miniprogram/` 目录；将 `project.config.json` 中的 `appid` 改为你的测试小程序 AppID。开发者工具的“不校验合法域名”只适合本地排障，不代表真机或上线可用。

## 真机验收清单

- iOS 与 Android 微信中都能打开 H5，首次进入和刷新不白屏。
- 横屏提示能正确引导用户旋转；微信 WebView 若拒绝全屏/方向锁定，应仍能在手动横屏后正常游玩。
- 开始游戏后 BGM、牌音和静音开关可用；切换后台再回来不会导致游戏卡死。
- 创建/加入房间、断线重连、结算确认下一局均可用。
- 3D 牌桌不会黑屏；中低端机持续一局不出现明显掉帧、崩溃或内存回收。

## 已知边界

- 这是 H5 容器，不会将 Vue DOM 页面转换为原生 WXML，也不会使用 `wx.request` 或 `wx.connectSocket`。
- 业务域名仅解决 `web-view` 的页面准入；H5 自身请求的 API、WebSocket、登录重定向、Cookie 和音频策略仍要在真机验收。
- 当前游戏请求浏览器全屏与横屏方向锁定；微信内嵌 WebView 对这些 API 的实际支持以真机为准。
- `config.js` 的默认地址特意不可访问，防止误将验证壳连接到未知环境。
