# 微信小游戏修复验证（2026-09-23）

## 交付行为

- 入口为单机模式 / 联机模式。联机卡片直接承接微信原生授权按钮，授权和服务端登录成功后进入联机大厅；取消后可重试，已登录用户无需重复登录。
- 单机和联机建房均提供 4、8、16 局。每次胡牌或荒庄计一局，连庄保留庄位但计入总局数。旧浏览器东风 / 半庄协议保持兼容。
- 牌桌顶部、两侧头像、底部手牌和中央 WebGL 区域分开；公告移到侧栏。昵称只显示一次，长昵称省略。
- 后端支持新模式及 SQLite / PostgreSQL 旧库约束迁移；SQLite 已验证迁移后历史战绩和外键引用完整、重复启动安全。
